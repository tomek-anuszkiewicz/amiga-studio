# Language Policy

- Answer in the language of the user's current request unless asked to switch.
- Persist repository code, identifiers, comments, documentation, plans, diagnostics, commits, and PR descriptions in English.
- Translate user concepts into idiomatic English before writing them into repository artifacts; do not quote untranslated Polish prompt phrases or metaphors in code or comments.
- Spoken-input presentation follows [audio-transcription.md](audio-transcription.md).
- The milestone gate scans staged additions for Polish; routine commits do not automatically invoke that scan. Explicit scanner commands are in [agent maintenance](../../docs/ai_agents.md#recording-and-validating-changes). Use no hooks.
