# Documentation Maintenance Rule

Whenever implementing, refactoring, or modifying any subsystem in this repository:

- **Mandatory Final Step (Definition of Done):** You must update the corresponding design document in [Obsidian/Amiga/Design](file:///d:/Programowanie/Amiga/Obsidian/Amiga/Design) whenever any architectural decision, timing model, data structure, or hardware quirk has changed or was clarified.
- The design specifications in `Obsidian/Amiga/Design/` are living, permanent references and must always stay synchronized with the active code.
