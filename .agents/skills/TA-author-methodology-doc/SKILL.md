# Author the selected narrative

Apply [the invocation contract](../../references/workflow-contract.md).
Executor: main session; result kind: `documents`.
Inputs: explicit document or unambiguous selected document, requested outcome,
source evidence and authorized write scope. A missing target returns `needs_input`.

1. Read the complete target and its source evidence. Use the
   [narrative criteria](../../references/narrative-criteria.md) for the article's
   conclusion-first progression; do not impose this structure on every task plan.
2. Map the existing argument, including important conclusions buried near the end.
   Write/restructure the assigned text around its main result, constraints,
   mechanisms, evidence and useful procedures.
3. Compare before/after content. Preserve unique technical reasoning, mechanisms,
   caveats, formulas, timing tables and useful diagrams/links, including material
   deliberately moved to an authoritative reference.
4. Return authored text/paths, decisions, actual checks and remaining uncertainty.

Stop after writing. Do not launch governance audits, broad verification or a commit.
