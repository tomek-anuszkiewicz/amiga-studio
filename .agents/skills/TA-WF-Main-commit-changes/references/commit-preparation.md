# Preparing meaningful commits

The commit assignment covers only its selected changes and staging.
Inspect their diff, preserve unrelated index entries, propose coherent commit
boundaries and English messages. Include diary content only when it belongs to
the selected work or is explicitly requested; ordinary commits require no entry.

Report actual tests, coverage, reviews and known gaps. Missing or failed checks
are not passing evidence. Run additional checks or reviews only within the
assignment. Final integrated tests and reviewers run on master in their separate stage. There are no required four-lane reviews, frozen trees, seals,
publication receipts or reusable-evidence records.

## Coverage during development and review

For selected production changes, assess meaningful protection for changed behavior
under the shared [testing criteria](../../../references/testing-criteria.md).
An actual coverage measurement, when selected, uses the existing verifier. Report
unmeasured areas and unresolved behavioral gaps separately. Preparation does not
start measurement, audits or repairs merely because evidence is missing.
