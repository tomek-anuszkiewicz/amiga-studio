# Skill results

Repository skills return text and a JSON object following
[result.schema.json](result.schema.json) and the shared
[result contract](../../.agents/references/workflow-contract.md).
The schema is a format reference. There is no result CLI, automatic renderer,
skill transition matrix, review router or delivery coordinator.

The user selects operations and combined sequences. Use ordinary Git commands
for selected commits and merges and the existing
[verification commands](../verification/README.md) for actual checks.
[Capture tools](capture/README.md) retain their separate telemetry and archive role.
